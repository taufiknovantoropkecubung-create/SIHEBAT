Pengaturan Integrasi Google Apps Script (GAS)

Hubungkan aplikasi ini dengan Google Spreadsheet untuk menyimpan seluruh data pembiasaan siswa (termasuk jam & foto bukti) secara otomatis di cloud!

Kosongkan URL jika hanya ingin menggunakan penyimpanan lokal di browser (Offline mode).

Cara Pemasangan di Google Sheets & Google Apps Script (3 Langkah):

1

Buat Google Sheet Baru

Buka sheets.new. Beri nama spreadsheet "Data SIHEBAT". Lalu buka menu Ekstensi > Apps Script.

2

Salin Kode AppsScript

Salin kode backend Code.gs di bawah ini dan tempel di editor Google Apps Script kamu, lalu tekan simpan (Ctrl+S).

3

Deploy sebagai Web App

Klik Deploy > New deployment. Pilih Web App, set "Who has access" menjadi Anyone. Klik Deploy dan tempelkan URL hasilnya di atas!
